# 微信 + Ollama 机器人

## 使用

登录微信电脑版 4.1.8.107 后，双击项目根目录的 `start.cmd`。脚本使用 Conda `WXbot` 环境，必要时尝试启动 Ollama。看到“正在监听: YY”表示启动成功；按 Ctrl+C 或关闭窗口停止。只允许运行一个机器人实例。

默认监听群 `YY`，并从会话列表发现新的私聊和群聊。私聊收到文本时回复；群聊只回复 @ 机器人或拍一拍机器人。群里通过 `@hyp 今天谁生日`、`@hyp 某某的生日是哪天` 等方式提问。微信账号在某个群里的昵称不同时，可以在 `config/config.json` 的 `chats` 中单独配置该群的 `bot_name`。

自动发现依赖微信会话列表显示新消息，已被阅读、未显示或静音状态下未暴露为新消息的聊天可能发现不了；启动前已有的未读消息不会自动回复。机器人需要打开独立聊天窗口，请保持桌面、微信和这些窗口可用，不要滚动聊天记录。窗口刷新、消息过多或模型响应较慢时可能漏消息。

## 性格和生日

编辑 `config/SOUL.md` 可以修改机器人的性格和生日名单。名单在 `birthdays` 代码块中，每行按 `姓名,月,日` 填写，日期为公历。机器人回答生日问题和每日播报都使用这同一份名单。`data/birthdays.txt` 是最初导入的备份，修改它不会更新实际名单。

每天本地时间 00:00 向 `YY` 播报当天生日及随后 7 个自然日的生日；没有登记生日时也会说明。机器人需要在播报时间运行并保持微信窗口可用，启动或恢复在 00:00–00:09 内可补发，当天超过这个时间不会补发。程序在 `data/birthday_state.json` 记录已播报日期，正常重启不会重复发送；如果发送结果未知或状态记录失败，请检查群聊和日志。

## 配置与目录

- `main.py`：程序入口。
- `src/`：消息处理和生日播报代码。
- `config/config.json`：模型、监听群、生日播报群等配置。
- `config/SOUL.md`：性格和生日名单。
- `data/`：生日原始备份及播报状态。
- `tests/`：离线测试。

`config/config.json` 的 `model` 可改成本机 `ollama list` 中的模型。`history_turns` 控制上下文轮数；群聊 @ 机器人后发送 `/reset` 可以清空该群上下文，重启也会清空。模型和其他配置改动需要重启机器人；`SOUL.md` 在回复和播报时重新读取。

首次在其他机器上使用时，先将 `config/config.example.json` 复制为 `config/config.json`，将 `config/SOUL.example.md` 复制为 `config/SOUL.md`，并自行填写生日名单；本人的生日资料不会提交到仓库。还需要 Windows、微信 4.1.8.107、Ollama、Python 3.11 的 Conda 环境 `WXbot` 和 `python -m pip install -r requirements.txt`。`start.cmd` 默认使用 `%USERPROFILE%\miniconda3\envs\WXbot\python.exe`，安装位置不同时请修改脚本中的 `PYTHON_EXE`。

消息会发送到配置的 Ollama 地址，默认是本机。微信 4.1.15.13 在本机无法提供所需的自动化控件，3.9 已提示版本过低，自动升级可能影响运行。
